## 🟢 Easy (5)
1. Use `SUM`, `AVERAGE`, and `COUNT` on a sample sales dataset.
2. Highlight duplicate values using Conditional Formatting.
3. Use `VLOOKUP` to pull a value from another sheet.
4. Create a simple bar chart from sales data.
5. Sort and filter a dataset by a specific column.

## 🔴 Hard (5)
1. Build a Pivot Table with slicers summarizing sales by region and product.
2. Use `INDEX`/`MATCH` to perform a two-way lookup.
3. Build a small dynamic dashboard using dropdowns (Data Validation) linked to a chart.
4. Use `SUMIFS`/`COUNTIFS` with multiple criteria.
5. Run a what-if analysis using a Data Table or Goal Seek.

## 📚 Theory (3)
1. What's the difference between `VLOOKUP` and `INDEX`/`MATCH`?
2. What is a Pivot Table, and when would you use one over a formula?
3. Explain the difference between absolute (`$A$1`) and relative (`A1`) cell referencing.
